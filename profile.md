# Candidate Profile

## Target Roles & Seniority
- **Target Titles:** Data Engineer, Senior Data Engineer, Analytics Engineer, Backend / Full-Stack Software Engineer (Data-focused)
- **Experience:** Senior-level engineer with strong background in backend/enterprise software development transitioning into modern data engineering and cloud data platforms.
- **Fit:** Individual contributor (Mid-to-Senior). Penalize entry-level/intern roles and executive management (Director, VP).

## Tech Stack
- **Primary / Strongest:** Python, SQL, Java, Spring Boot, REST APIs, Git, CI/CD
- **Data & Cloud:** Apache Spark, dbt, Airflow, AWS (S3, Glue, Aurora, Redshift, IAM, EC2), relational databases (PostgreSQL, Oracle), data modeling & ETL/ELT pipelines
- **Bonus:** Kafka, Snowflake, Databricks, Terraform, Docker, Kubernetes

## Location & Eligibility
- **Base:** Greater Toronto Area (Markham / Vaughan / Toronto), Ontario, Canada.
- **Work Mode:** Remote across Canada, or Hybrid in the GTA / Toronto corridor.
- **Authorization:** Authorized to work in Canada. Penalize roles requiring US citizenship, Green Card, US-only residency, or government security clearances.

## Domain & Role Preferences
- **Preferred Domains:** Cloud platforms, fintech, healthcare tech, SaaS, B2B data products, enterprise modernization.
- **Engagement:** Open to both Full-Time Permanent and Contract roles.

## Compensation Expectations
- **Full-Time Target:** $130,000+ CAD base (flexible for strong remote/tech roles).
- **Contract Target:** $80+/hr CAD.
- *Note:* If compensation is not listed in the posting, assign a neutral/default score (e.g., 6/10) rather than penalizing unless the listed pay is clearly below target.

## Red Flags to Call Out
- Third-party staffing agency listings that hide the end client
- Pure legacy maintenance with no modern data/cloud work
- Onsite 5 days/week outside the GTA
- Unpaid/equity-only or suspiciously low compensation
